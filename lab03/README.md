### Задание 2 **(3)**
*Запишите правила неявного преобразования типов в языке С++*

*Проверка отчета будет включать проверку знания правил.*

*Преобразования при присваивании* - значение правой части приводится к типу левой части. То есть int = 10, а double = 10.0.

*Преобразования при арифметических действиях* - если операнды по типу меньше int, то сначала приводится всё к нему, и только потом всё преобразуется в "больший" тип данных. То есть short в int, int в unsigned int, unsigned int в long, long в unsigned long и т.д.

*Преобразования с логическими значениями* - любое числовое значение преобразуется к bool. То есть 0 становится false, любое ненулевое значение - true.

### Задание 6 **(2)**

Рассмотрите следующий фрагмент программы. 
```
int a = -1, b = 1;
unsigned int c = 1;
std::cout << a*b << std::endl;
std::cout << a*c << std::endl;
```
* *Объясните работу этой программы, используя правила неявного преобразования типов*
* *Что произойдет, если тип* **int** *заменить на* **short**, а **unsigned int** на **unsigned short**?*

В первом случае вывелось -1, потому что оба операнда знакового типа.
Во втором случае вывело 4294967295, потому что если в операции участвуют операнды разных типов, то компилятор приводит их сначала в int (если она оба меньше int), и потом если один из операндов "шире", то оба операнда приводятся к самому "широкому" типу. При совпадении знакового и беззнакового типов, всегда выигрывает беззнаковый.

Но если int поменять на short, а unsigned int поменять на unsigned short, то в обоих случаях выведится -1.

### Задание 7 **(2)**
*Рассмотрите следующий фрагмент программы.*
```
int x = 7, y = 4;
long double d = 0.25;
cout << (x / y) / d << endl;
cout << (x / d) / y << endl;
long a = 200000, b = 200000;
long long c = 200000;
std::cout << (a * b) * c << std::endl;
std::cout << a * (b * c) << std::endl;
```
*Почему изменения порядка действий приводит
к изменению результата? Объясните работу этой программы, используя правила неявного преобразования типов*

Изменение порядка действий приводит к изменения результату, потому что разные типы приводятся сначало к int (если они меньше), и после всё преобразовывается  к ещё более "широкому" типу.

1 часть кода:
В 1 выражении у нас оба операнда типа int, поэтому никакого преобразования не происходит, и всё выполняется целочисленное деление (7/4 = 1). Но 2 действие уже преобразует тип int в long double (поскольку он шире, чем int), где у нас выходит (1.0/0.25) и получаем ответ 4.
Во 2 выражении у нас сразу int преобразуется в long double (поскольку он шире, чем int), и получаем пример (7.0/0.25) где получаем 28.0. После у нас идёт снова преобразование типов (int преобразуется в long double), где мы получаем (28.0/4.0), и ответ = 7.

2 часть кода:
В 3 выражении никакого преобразования не происходит (т.к. операнды одного типа). Результат равен 200000 * 200000 = 40000000000, но происходит переполнение (не помещается в 32-битный long) и получается переполнение (1345294336). Во 2 действии long преобразуется в long long (поскольку он шире long), и получаем выражение (1345294336 * 200000), где ответ равен 269058867200000.
В 4 выражении сразу происходит преобразование типов (long в long long), где мы получаем выражение (200000 * 200000 = 40000000000). Затем умножаем (40000000000 * 200000) и получаем ответ равный 8000000000000000.
