### Задание 6 **(2)**

*Для какого минимального значения* $n$ *программа на С++ выведет* **inf**? *Объясните
ответ.* *Что произойдет, если тип* **double** *заменить на* **long double**?
```
int n=...;
double s = pow(2, n);
std::cout << std::fixed << s << std::endl;
```

Ответ:  
Для типа double под порядок отводится 11 бит, а смещение равно 1023. Так как все единицы в поле порядка зарезервированы под спецтальные значения inf и 
NaN, то максимальный хранимый порядок равен 2046. Истинный порядок вычисляется: 2046 - 1023 = 1023. Получается, что при 2^1023 число поместится, а при 1024 уже нет, потому что произойдёт переполнение.
Если заменить тип на long double, то под смещение будет отводиться уже 15 бит (2^14 - 1 = 16383) и максимально истинный порядок получится 16383. Значит при 16384 будет inf.

### Задание 8 **(2)**

*Какое минимальное натуральное число при преобразовании в тип* **double** *записывается с погрешностью? Объясните
ответ. Почему следующее за ним число уже выводится без погрешности?*

Ответ:  
Минимальное натуральное число записываемое с погрешностью - это 2^53 + 1. В типе double мантисса имеет 53 бита точности. Число 2^53 + 1 в двоичном представлении требует 54 бита, поэтому
его младшая единица не помещается и теряется. Следующее за ним число, 2^53 + 2, записывается без погрешности потому, чтто его можно представить как 2 * (2^52 + 1). В двоичной системе это 
просто сдвигает запятую, и для хранения значащих цифр ему как раз хватает ровно 53 допустимых бита.
